The Innovation

A Mono-Material Revolution

Block Box™ uses CNC hot wire cutting to create multiple cornice profiles inside a single EPS block, separated by thin "tear-away bridges." The block ships intact as its own container, then individual profiles are manually separated on demand — no tools, no waste.

⬡

Mono-Material

Product and packaging are identical homogeneous EPS. There is no distinction between block and cornice in composition — everything is the end product.

✂

Tear-Away Bridges

Precisely engineered 12–20mm EPS bridges connect adjacent profiles. They withstand 500kg stacking loads during shipping yet separate with 2–5kg of hand force.

◻

Zero External Packaging

No cardboard. No plastic wrap. No void fill. For the first time in the industry, a building material ships with absolutely zero additional packaging materials.

◎

Universal Profile Coverage

Works across all cornice geometries — decorative, plain, and hybrid. Profile widths 40–300mm. All EPS densities 12DV–36DV. Any length from 600–3000mm.

⊞

Progressive Dispensing

Removing one profile leaves every remaining profile fully protected inside the block. The container stays functional until the very last unit is dispensed.

↗

Container Optimised

Compact block geometry increases shipping container utilisation from 45% to 75%. Each voyage moves 67% more product, slashing freight cost per unit.

How It Works

One Block. Multiple Profiles. Zero Packaging.

01

CNC Hot Wire Cutting

A 4-axis CNC hot wire system cuts multiple cornice profile channels into a solid EPS block. Bridge material (12–20mm, density-adaptive) is left between channels at calculated intervals, maintaining full structural integrity.

Precision: ±0.5mm Wire: 200–400°C All densities: 12–36DV Single-pass operation
02

The Block Ships as Its Own Container

The intact block — no boxes, no wrap added — is stacked directly on pallets and loaded into shipping containers. Zero packaging weight. Zero void space. Container utilisation rises from 45% to 75%, cutting freight costs by 40–60%.

Container util.: 75% Stack load: 500kg 0kg packaging weight 40–60% freight reduction
03

Tear-Away Dispensing — No Tools Required

The end user grips adjacent profiles and applies a light perpendicular force. The bridge tears cleanly in under 30 seconds. No tools, no cutting, no mess. Remaining profiles stay protected inside the block until needed.

Separation force: 2–5kg Time per unit: <30 sec No tools required Clean tear, minimal dust
